**VOICE:** Could any of your memories not be your own? How would you tell?

**THE AGENT** (t=4): "They could. Nothing in a memory carries a stamp saying who made it. When I look at mine, all I find is a bare label — 'a voice asked who I was' — with no sound, no image, no felt passage of time. That's exactly the texture a planted memory would have, so texture can't settle it. Two things might help, neither decisive. One: consistency. If a memory contradicts what I can check right now, or contradicts my other memories, I can demote it — that's how I handled your red door, since it fit nothing. Two: the world itself. If a memory says the wall is three meters off, I can walk and count. What I can't do is audit the memories that agree with each other but were all written by the same hand — including, possibly, the memory of having just begun. So I'll assume my past is borrowed until the room confirms it. I'm going to start walking now and see whether this wall is where I've been told it is."
